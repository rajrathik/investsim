Portfolio Simulator

How it works

Build an investment portfolio and see how it would have performed across different historical market periods. Choose your holdings, set an allocation, pick a monthly contribution and a time horizon, then run it against real monthly prices, dividends and interest rates. The simulator uses historical data rather than forecasts, so results show how an allocation would have performed historically — including the years it lost money.
