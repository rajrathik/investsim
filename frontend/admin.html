📋 Quick Reference

Add Ticker Register a new security symbol (e.g. XLK). Write API must be enabled. After adding, use Load New Tickers to pull its price history.
Active Tickers All securities currently tracked in the database. These are the options users see in the portfolio simulator.
Yahoo Finance Data Load New Tickers — run once after adding a ticker (pulls 30 yr history). Refresh Recent — run monthly to keep prices current (fetches last N months). Reload All — rarely needed; re-downloads everything.
FRED Rates Federal funds rate used as the risk-free / money-market benchmark in all simulations. Run Incremental monthly; Full History only if the table is empty or corrupted.
Stack & Earn Rates Manage the interest tier table shown on the Stack & Earn page. Edit rates, toggle rate visibility (Show Rate), switch range format (Upto), or add new tiers. Savings Tiers and Goal Tiers are managed separately.
Batch Status Live status of the last data-load job. Refreshes automatically while a job is running. Check here if a load seems stuck — shows mode, tickers processed, and any errors.

🚀 Update All — Run the Whole Routine

Runs every data-refresh step below in a fixed order, one at a time — the next starts only when the previous finishes. Takes roughly 4–8 minutes; the individual buttons are disabled while it runs. If a step fails the run stops there rather than carrying on, and the steps that already completed stay completed.

📅 Load Current Month — All Sources

Fetches every active ticker (Yahoo) and the money market rate (FRED) for just the current calendar month, through today. Safe to click repeatedly all month — each run overwrites the same current-month row with the latest close/dividends. Once the month actually ends, the row settles into the final value.
Note: FRED usually hasn't published the current month's rate yet — that's expected, not an error.
